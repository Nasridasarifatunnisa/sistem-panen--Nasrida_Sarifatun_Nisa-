# Sistem Pencatatan Hasil Panen Digital

Aplikasi Python sederhana untuk mencatat hasil panen petani (nama petani,
komoditas, jumlah kg, harga per kg) serta menghitung total dan diskon hasil
panen.

## Fitur
- Mencatat data hasil panen (`tambah_panen`)
- Menampilkan seluruh catatan panen (`tampilkan_panen`)
- Menghitung diskon dari total harga (`hitung_diskon`)

## Cara menjalankan
```bash
python panen.py
```
